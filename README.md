Proyecto orientado a la gestión y automatización de información de trabajadores, nacido de una necesidad real de organización y procesamiento de información.

Este proyecto representa una de las razones principales por las que decidí profundizar en programación: buscar soluciones para procesos que pueden volverse complejos cuando la información se maneja de forma manual.
 
[👉 Ver proyecto](https://github.com/elbaneira/Bootcamp-Full-Stack-Python-grupo-1/tree/main/AYUDANTIA/Proyecto%20-M%C3%B3dulo%203/mano_obra_nomina)

Tecnologías: Python · Automatización · Gestión de datos

2. 👥 Gestor Inteligente de Clientes — GIC

Aplicación desarrollada en Python aplicando conceptos de Programación Orientada a Objetos.

Incluye gestión de clientes, operaciones CRUD, encapsulación, validaciones, persistencia de información y comparación de objetos.

El proyecto también incorpora documentación y diagrama UML, utilizado para representar la estructura antes de implementar el código.

[👉 Ver repositorio](https://github.com/elbaneira/Bootcamp-Full-Stack-Python-grupo-1/tree/main/AYUDANTIA/Proyecto%20-%20M%C3%B3dulo%204)

Tecnologías: Python · POO · CRUD · JSON · UML
